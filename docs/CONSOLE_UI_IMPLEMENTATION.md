# 控制台 UI 实施说明

基线：feature/ovs-network-topology / 27630300e39cbd877fc8a87eaaf8c5f40b118f92。

## 已实现

- 单一 AppLayout：固定 56px 顶栏，232px/64px 主导航，独立滚动工作区。
- 统一 tokens.css：颜色、字体、尺寸与间距；48px 表格行高。
- 浏览器 History 路由、管理员/用户页面边界、403/404、会话失效处理。
- 管理员优先进入总览；资源与任务来自实际 API，每 15 秒刷新，隐藏标签页暂停请求。
- CPU 使用率和历史趋势尚无采集 API，显示暂无数据；内存只汇总未过期样本。
- 虚拟机列表支持服务端搜索、状态/节点过滤、分页、详情跳转。
- 八个固定详情标签页、按状态与权限显示操作、确认弹窗、任务进度抽屉。
- 五步创建向导：动态读取授权节点、已审核镜像和网络；复用幂等键。
- noVNC 按需加载，避免进入控制台首页即下载 VNC 模块。
- 节点六标签详情、真实目录容量汇总、网络列表与详情抽屉、五步网络登记。
- 网络 IPv4 地址池即时校验；后端强制检查 CIDR 重叠、网关、VLAN、地址池。
- 网络被实例引用时禁止删除及直接变更关键连接配置。
- 用户/角色两标签、真实角色权限只读展示、服务端审计日志分页。

## API 与权限

保留原有 API 响应，避免直接改动既有客户端契约。

新增 /api/v1/admin/ 与 /api/v1/operator/ 命名空间，覆盖 dashboard、vms、
生命周期、控制台、tasks、audit、quota。命名空间由服务端身份校验；
前端从 /auth/me 的 console_scope 选择对应 API。

原有 /instances 与 /tasks API 同样执行资源范围过滤，兼容地址不会绕过校验。
普通账号只能访问自己创建且节点授权允许的虚拟机、其磁盘，以及本人发起的任务。
管理员使用全局资源范围。全局网络修改、监控与节点管理另有服务端管理员边界。

账号首次创建所用的幂等键按账号散列，重复请求可复用已完成任务；规格不一致返回冲突。
创建时在数据库事务内锁定节点和账号，以串行校验节点容量、账号配额及幂等请求。

普通账号配额通过环境变量配置，默认值：

| 变量 | 默认值 |
| --- | --- |
| USER_QUOTA_INSTANCES | 10 |
| USER_QUOTA_VCPU | 32 |
| USER_QUOTA_MEMORY_MIB | 65536 |
| USER_QUOTA_DISK_GIB | 1024 |

关机与创建中的实例仍占用配额。管理员不受账号配额限制。
系统设置支持持久化修改全体普通账号配额，未保存设置时使用环境变量默认值。
当前没有自定义项目或逐账号配额编辑页面。
Operator 沿用仓库的普通资源操作账号定位；本次没有把既有 Operator 自动提升为全局运维管理员。

## 能力限制

- 集群、资源池、存储池、快照与系统设置已增加 API 和页面，实施边界见 [基础设施功能说明](INFRASTRUCTURE_FEATURES.md)。
- 集群用于节点组织；资源池用于虚拟机分组和已分配资源限额校验，不包含 HA 或自动迁移。
- 存储池直接查询 libvirt，支持创建受管目录池；不提供 LVM/NFS 创建或任意宿主机挂载。
- 备份、硬件修改、自定义角色编辑尚无完整后端能力，界面保留说明。
- 子网/DHCP 表单登记元数据；不自动重配宿主机 OVS、dnsmasq 或 NAT。
- 网络尚无节点绑定、运行状态、网络 UUID、同步时间字段，界面明确标明。
- CPU/IO/网络时序指标未采集；趋势时间范围选择不会生成模拟曲线。
- 虚拟机列表暂不并发请求每台机器的 IP；没有缓存地址时显示破折号。
- 普通用户可以查看授权虚拟机快照；快照写操作仅向管理员开放，独立备份尚未实现。
- 基础设施功能新增 infrastructure 初始迁移和 tasks/0005 迁移；升级必须执行 migrate。
- 当前 UI 沿用 React + TypeScript + Vite 与已有组件，未额外引入 Ant Design。
