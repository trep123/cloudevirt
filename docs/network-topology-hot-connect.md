# 网络拓扑与热接入

网络管理 → 拓扑：展示全部已登记网卡，而非只画主网络。支持节点筛选、虚拟机/网络名搜索、缩放、重置视图及点击虚拟机突出全部连线。一次聚合请求从数据库读取配置拓扑，不对每台虚拟机串行调用 Agent。数据代表登记配置与最后观测状态，过期状态用虚线显示；页面可见时每 15 秒刷新。当前单次最多 300 个网络和 300 台授权虚拟机，非全量实时监测画布。

平台管理员且拥有实例修改权限时，可以从蓝色虚拟机端口拖至网络端口，或反向拖线；也可依次点击端口/使用 Tab 与 Enter，Esc 取消。确认后新增 VirtIO 网卡，保留现有网卡；不是替换、断开或移动已有网卡，不操作宿主机物理网卡或上联。跨节点、重复网络、管理网络、不可用网络、过期/异常虚拟机及 8 网卡上限均限制接入。

已关机实例沿用冷配置任务；运行中实例发送 live=true，服务端要求最近 60 秒内确认的运行状态、节点可调度且 Agent 声明 nic_hotplug 能力。普通用户不能提交硬件变更，运行中其他硬件操作仍保持关机要求。所有动作经过对象权限、幂等键、任务互斥、审计与任务执行前授权复核。

节点热接入先校验运行态与持久态 UUID、网卡参数和快照，再按相同 MAC 先同步持久配置、再接入运行配置，回读两者后才确认成功。存在快照时拒绝热接入，避免快照一致性问题。物理 PCI 插槽、网桥或客体驱动不支持时任务失败，不伪造连线。

若持久配置成功而运行配置失败，不盲目回滚或生成新 MAC；任务保留供核对，重试原任务按相同 MAC 补齐缺失一侧。前端不提前添加成功连线，使用现有任务进度组件反馈执行与失败；拓扑刷新后显示服务端登记结果。
