# 普通用户网络与数据盘权限

普通用户在 `/app/networks` 查看已授权节点的可用业务网络和自己虚拟机的拓扑，可以拖线或在虚拟机「网络」页新增网卡。运行中的虚拟机使用已验证的热接入，关机虚拟机修改持久配置；原有网卡不被替换。不能创建、编辑或删除网络、管理宿主机网桥、移除网卡，也不能连接管理网络、其他节点或他人的虚拟机。

普通用户在自己虚拟机「磁盘」页可以关机后新增数据盘、卸载数据盘、重新挂载已卸载数据盘。卸载仅解除虚拟机挂载并保留文件；要永久删除，需对已卸载的数据盘再次确认「删除文件」，由异步任务核验后删除。系统盘、未登记文件、CPU/内存和磁盘扩容仍由平台管理员管理。

后端使用 `instances.connect_network_instance` 和 `instances.manage_data_disk_instance` 两个独立权限；永久删除文件仍需 `instances.delete_disk_instance`。内置 Operator 与 Viewer 角色包含这些本人资源权限，不再包含 `networks.manage_network`。提交任务与实际执行时都重新核对角色权限、实例所有权、节点范围、网络可用性、磁盘角色和任务预留；前端按钮显隐不构成安全边界。
