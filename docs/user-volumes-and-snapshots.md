# 用户数据卷与快照权限

- 学员（Operator）与一般用户（Viewer）可查看自己的数据卷，清理自己已删除实例保留或已卸载的磁盘。使用中的磁盘不可直接删除；节点检查所有域、快照和 backing chain 引用。
- 用户仅可管理自己未删除虚拟机的快照：创建、恢复、删除。独立权限码 `instances.manage_snapshot_instance`，支持通过角色撤销；同时遵守节点授权范围。
- 所有快照变更要求虚拟机已关机、观测状态未过期、没有其他活动任务；节点再次验证实际状态与快照类型。仅支持现有关机内部快照能力。
- 恢复覆盖快照之后的变更；删除恢复点不可逆，前端均需确认。具有子快照时先处理子快照。节点未开启破坏性操作时不可恢复或删除。
- 每次操作通过幂等异步任务提交并审计；Worker 执行快照操作前重新检查所有权、权限、节点状态和关机条件。
- 管理员保留全局管理权限。用户不能以修改 URL、实例 ID 或任务内容访问他人数据卷/快照。虚拟硬件的新增、卸载、扩容仍限管理员。
- 用户导航新增“我的数据卷”；不展示管理员的节点容量汇总或存储池管理入口。已删除卷默认隐藏，可通过历史记录筛选查看。
