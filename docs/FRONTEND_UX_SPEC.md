# CloudVirt 前端排版与交互规范

- 版本：1.0（草案）　日期：2026-10-26
- 上游：《手册》第 13 章；接口见 ARCHITECTURE.md；权限见 RBAC_AND_SETTINGS.md；数据见 DATA_MODEL.md。
- 定位：页面结构、排版、组件与交互的**实现前约定**；不替代设计稿，但足以直接编码。

## 1. 目标与约束

| 项 | 约定 |
| --- | --- |
| 技术栈 | React + TypeScript + Vite；严格模式 `strict: true` |
| API 访问 | 全部经 `src/api/`，禁止组件自拼 URL |
| 权限 | 前端仅做可见性控制，**不是权限边界**；越权由后端返回 403 并在前端提示 |
| 状态表达 | 禁止只用颜色，必须颜色 + 图标/文字 |
| 危险操作 | 强制停止、彻底删除、镜像删除必须二次确认对话框 |
| 轮询 | 任务/状态轮询必须在页面卸载时清理，带退避与超时上限 |
| 错误展示 | 必须展示可读消息与 `request_id`/任务 ID，禁止只显示“未知错误” |

## 2. 目录结构

```text
apps/web/src/
├── api/            # 唯一 API 层：client（超时/401/解析）、modules/*.ts、errors.ts、types.ts
├── pages/          # 页面：路由一一对应，目录名即路由段
│   ├── login/
│   ├── dashboard/
│   ├── nodes/{list,detail}/
│   ├── images/{list,import}/
│   ├── instances/{list,create,detail}/
│   ├── tasks/{list,detail}/
│   ├── admin/{users,roles,settings}/
│   └── audit/
├── components/     # 通用组件：DataTable、StatusBadge、ConfirmDialog、TaskProgress、EmptyState、Toast、PageHeader
├── layouts/        # AppLayout（侧边栏+顶栏）、AuthLayout
├── hooks/          # usePolling、useAuth、usePermission、usePagination
├── types/          # 与后端枚举对齐的 TS 类型与常量
└── utils/          # 格式化（字节/MiB/GiB、时间 UTC→本地）、校验
```

## 3. 路由与权限矩阵

| 路由 | 页面 | 最小权限 | 可见角色 |
| --- | --- | --- | --- |
| `/login` | 登录 | 匿名 | 全部 |
| `/` | 仪表盘 | 登录 | Admin/Operator/Viewer |
| `/nodes` | 节点列表 | `node.view` | 全部 |
| `/nodes/:id` | 节点详情 | `node.view` | 全部 |
| `/images` | 镜像列表 | `image.view` | 全部 |
| `/images/import` | 镜像导入 | `image.upload` | Admin/Operator |
| `/instances` | 实例列表 | `instance.view` | 全部 |
| `/instances/create` | 创建实例 | `instance.create` | Admin/Operator |
| `/instances/:id` | 实例详情 | `instance.view`（对象级） | 全部（受对象级限制） |
| `/tasks` | 任务列表 | `task.view` | 全部 |
| `/tasks/:id` | 任务详情 | `task.view`（对象级） | 全部 |
| `/admin/users` | 用户管理 | `user.manage` | Admin |
| `/admin/roles` | 角色与权限 | `user.manage` | Admin |
| `/admin/settings` | 系统设置 | `settings.manage` | Admin |
| `/audit` | 审计日志 | `audit.view` | Admin（可配置对 Operator 只读） |

- 路由级权限只做跳转拦截；按钮级权限用 `usePermission(codename)` 控制**隐藏 + 禁用**，后端仍独立校验。

| 区域 | 规则 |
| --- | --- |
| 顶栏 | 固定高度；环境标签生产环境用醒目但不误导的样式；告警入口显示 ACTIVE 数量；用户菜单含「个人设置 / 修改密码 / 退出」 |

| 内容区 | 最大宽度限制，宽屏居中；表格可横向滚动 |

## 5. 页面线框

### 5.1 登录页

```text
┌──────────────────────────────┐
│           CloudVirt          │
│   用户名 [____________]      │
│   密  码 [____________]      │
│   [ 登录 ]                   │
│   错误提示区（含 request_id）│
└──────────────────────────────┘
```

- 登录失败不提示“用户名不存在”；连续失败达阈值显示锁定提示；成功后跳转原目标页。
- 会话失效（401）在任何页面都要清除本地会话并跳登录。

### 5.2 仪表盘

```text
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ 节点在线 3/4 │ 实例运行 12  │ CPU 使用率   │ 存储剩余 62% │
└──────────────┴──────────────┴──────────────┴──────────────┘
┌────────────────────────────┬──────────────────────────────┐
│ 活跃告警（类型/级别/时间） │ 最近任务（状态/耗时/操作者） │
└────────────────────────────┴──────────────────────────────┘
┌───────────────────────────────────────────────────────────┐
│ 节点资源概览（每节点：CPU/内存/存储 + 采样时间与过期标记）│
└───────────────────────────────────────────────────────────┘
```

- 每个统计卡必须标注统计口径与采样时间；数据过期时显示“数据可能过期”标记。

```text
详情：基本信息卡（endpoint/版本/状态/最近心跳/连续失败）
```

### 5.4 镜像列表 / 导入

```text
列表：[搜索][格式][状态]                     [+ 导入镜像]
列：名称 | 格式 | 大小 | 虚拟容量 | 状态 | 校验和(前8位) | 创建者 | 时间 | 操作（详情/删除）

导入（对话框或页面）：
  方式：① 上传文件（分片/流式，显示进度与速度）② 登记已有文件（服务端路径下拉）
  字段：名称*、格式*（自动识别，可覆盖需说明）、OS 系列/版本（可选）、文件*
  限制提示：允许扩展名、单文件大小上限、并发上限
  进度：上传% → 校验中（SHA-256）→ 格式复核（qemu-img）→ READY/FAILED（展示错误码）
```

- 被实例引用的镜像，删除按钮禁用并在提示中说明引用数量。

```text
列表：[搜索][节点][观测状态][任务状态]             [+ 创建虚拟机]
列：名称 | 节点 | 规格(vCPU/内存/磁盘) | 观测状态 | 任务状态 | 创建者 | 时间 | 操作
     观测状态=UNKNOWN 或 数据过期 时显示过期标记；操作按钮按权限与当前状态启用/禁用

创建（单页表单）：
┌─ 基本信息 ────────────────────────────┐
│ 名称*（字符集/长度提示，实时重名提示）│
└──────────────────────────────────────┘
┌─ 资源配置 ────────────────────────────┐
│ 节点* [下拉]   可用资源：CPU 8 / 内存 20GiB / 存储 500GiB（采样时间 xx）│
│ 镜像* [下拉]（不可用镜像禁用并标注原因）                               │
│ 网络  [下拉]（白名单，管理网不可选）                                   │

│ 开机自启 [勾选，仅后端已实现时显示]                                    │
└──────────────────────────────────────┘
            [取消]  [创建（提交中禁用）]
→ 提交后跳转任务详情，展示进度条与阶段（VALIDATING→PREPARING→CREATING→VERIFYING）

详情：
  头部：实例名 + 观测状态徽标 + 任务状态 + [启动][关机][重启][强制停止][删除]
  配置卡：UUID、节点、镜像、网络、vCPU/内存/磁盘、autostart、创建者、时间
  磁盘卡：路径、格式、请求容量、实际占用、状态、孤儿标记
  任务卡：当前/最近任务（ID、阶段、耗时、错误码）、重试与取消（按权限）
```


## 6. 通用组件规范

| 组件 | 规范 |
| --- | --- |
| DataTable | 列定义集中；支持排序、筛选、分页（page size 有上限）、空态、加载骨架、行操作区；禁用横向滚动时的列挤压 |
| StatusBadge | 颜色 + 图标 + 文字三要素；未知/过期用中性色 + 明确文字 |
| ConfirmDialog | 三级：普通确认（删除实例记录）、危险确认（强制停止：说明断电风险）、输入确认（彻底删除：需输入实例名并勾选“同时删除磁盘”） |
| FormField | 标签、必填标记、校验提示、帮助文本、错误文案来自后端时原样展示并附字段定位 |
| Toast | 成功/失败/警告；失败必须包含 `request_id` 或任务 ID，可一键复制 |
| TaskProgress | 阶段进度 + 轮询状态 + 超时提示；任务终态后停止轮询 |
| EmptyState | 区分“无数据”与“无权限/被过滤”，并给出下一步操作入口 |
| ErrorBoundary | 页面级兜底，展示可读信息与 request_id，禁止暴露堆栈 |

## 7. 状态语义（颜色 + 图标 + 文字）

| 语义 | 颜色 | 图标/前缀 | 文字 | 适用 |
| --- | --- | --- | --- | --- |
| 正常/运行中 | 绿 | ● | 运行中 | RUNNING、ONLINE、READY、SUCCEEDED、ACTIVE(INFO) |
| 停止/离线 | 灰 | ○ | 已关机 / 离线 | SHUTOFF、OFFLINE、DELETED |
| 处理中 | 蓝 | ◐ | 处理中 | PENDING/PREPARING/CREATING/VERIFYING/VALIDATING |
| 告警/降级 | 黄 | ▲ | 降级 / 警告 | DEGRADED、WARNING、RECONCILING |
| 错误/失败 | 红 | ✕ | 失败 / 崩溃 | FAILED、CRASHED、CRITICAL |
| 未知/过期 | 中性 + 虚线边框 | ? | 未知（数据过期） | UNKNOWN、stale=true、PAUSED |

- 色盲友好：形状/图标与文字必须同时存在；同一表格内不得仅靠背景色区分。

## 8. 表单校验规则（前端即时提示，后端最终校验）

| 表单 | 字段 | 前端规则 |
| --- | --- | --- |
| 创建实例 | 名称 | 3–64 字符，`[a-zA-Z0-9-_]`，不以连字符开头结尾；实时重名提示 |
| 创建实例 | vCPU / 内存 / 磁盘 | 正整数；上限取自系统设置；超出可用资源时提示剩余量 |
| 创建实例 | 节点 / 镜像 / 网络 | 必选；镜像非 READY、节点离线、网络不可用均禁用选项并说明原因 |
| 镜像导入 | 文件 | 扩展名白名单；大小上限（取自设置）；上传中显示进度，失败可重试 |
| 用户创建 | 用户名 / 密码 | 用户名 3–64；密码长度与复杂度策略（取自设置）；初始密码展示一次并提示改密 |
| 系统设置 | 数值项 | 类型与范围校验，越界即时提示；修改需二次确认 |

## 9. 关键交互流程

1. **创建实例**：填表 → 提交（按钮禁用防重复）→ 收到 202 与任务 ID → 跳转任务详情 → 轮询（初始间隔短，指数退避，最长间隔上限，超时上限后提示“仍在后台执行，可稍后查看”）→ 终态后刷新实例详情。
2. **危险操作**：点击 → 确认对话框（说明后果与不可逆点，彻底删除需输入名称并勾选磁盘处理）→ 提交 → 任务轮询 → 失败保留在详情页并展示错误码与任务 ID。
3. **401 处理**：任意请求返回 401 → 清除本地会话 → 跳转 `/login` 并保留回跳地址。
4. **403 处理**：不跳登录，展示“无权限执行该操作”并保留当前页面数据。
5. **409 处理**：展示冲突原因（如 `OPERATION_IN_PROGRESS`、`INSUFFICIENT_RESOURCE` 及不足的资源类型），并给出“查看当前任务”入口。
6. **轮询清理**：`usePolling` 在组件卸载、路由切换、页面隐藏时停止；同一资源不得存在多个并发轮询。
7. **刷新与缓存**：列表页提供手动刷新；节点切换/筛选变化时重新拉取可用资源。

## 10. 文案、可访问性与国际化

- 文案规则：操作结果用“对象 + 动作 + 结果”；错误文案必须可执行（告诉用户下一步），并附错误码与 request_id。
- 可访问性：按钮有可读名称；对话框焦点管理与 Esc 关闭；表格有表头语义；颜色对比度达标。
- 国际化：界面文案走 i18n 资源文件；枚举值在前端映射为本地化文案（枚举本身保持英文大写存储）。
- 时间展示：统一转为本地时间展示，并在关键位置提供 UTC 原值与相对时间（如“3 分钟前”）。
