# 直接使用节点目录中的系统磁盘

平台管理员在创建向导的基本信息页启用“直接使用节点已有系统盘”，选择节点，在页面显示的节点磁盘目录（Agent DiskDir）内选择文件，或填写规范相对路径（含子目录），点击“检查磁盘”。检查通过后按实际虚拟容量显示，不能在本向导扩缩容；CPU、内存、固件、设备及网络仍可配置。

文件不必在镜像页导入，也不要求已有数据卷记录。新虚拟机直接使用原文件，不克隆、不覆盖、不格式化、不调整容量，不注入 cloud-init。创建后运行的虚拟机将直接修改原文件。删除虚拟机默认保留磁盘；若管理员明确选择同时删除磁盘，会删除这个原文件。

当前直接使用模式支持独立 QCOW2 文件；不支持 RAW、ISO、依赖 backing/data-file 的磁盘。候选目录列表只扫描目录第一层，子目录文件可填写相对路径检查。不是任意宿主机绝对路径访问；允许根目录由节点部署配置决定，前端不能扩大。

普通用户不能列目录、检查文件或提交直接挂载请求。管理员访问同样受节点创建与操作授权限制。后端预检/正式提交检查真实容量，使用节点行锁与唯一磁盘记录防止重复认领；执行任务前再次检查管理员身份。Agent 在排他磁盘引用锁内核对虚拟机、持久定义、快照、backing/data-file 引用及格式，避免并发创建重复挂载；已有域重试遵循创建日志幂等，不重新创建或覆盖原文件。

接口：GET /api/v1/admin/vms/system-disk-sources/?node=ID 列目录和未登记候选；附加 path=相对路径 检查文件。创建提交 existing_system_file 和 node，不提交 image；不可与部署模板、旧保留盘克隆入口或初始化混用。没有镜像的实例 image 为空，来源路径写入创建快照。

旧 existing_system_disk 克隆协议仅保留兼容性，不再作为前端“已有系统盘”选项。
