# 系统盘克隆方式

创建虚拟机的存储步骤提供全克隆、链接克隆。全克隆为默认镜像部署方式，复制为独立 QCOW2；链接克隆生成 QCOW2 差异盘。平台管理员使用节点已有系统盘文件时，也可选择这两种模式，或保留直接使用原文件的方式。直接模式容量固定；两种克隆模式可扩容但不可缩容。ISO 安装只支持独立系统盘，不支持链接克隆。

链接克隆首次将经校验的源盘准备为节点内部 .bases/ 只读基础副本，按内容摘要缓存；后续相同来源复用基础副本并建立差异盘。基础副本不受原镜像删除、原目录文件变更的影响；写入只发生在实例差异盘中。首次准备需要额外时间和空间，后续部署更快。为避免容量虚报，调度仍按完整虚拟容量保守预留。

实例不能脱离基础副本独立移动。基础缓存目前保守保留、不自动回收；清理必须先核对所有 backing 链。受管磁盘清理会检查 backing/data-file 依赖，禁止删除仍被引用的基础盘。内部隐藏路径不可作为管理员直接使用的原盘，避免误写基础副本。

克隆模式写入任务与实例创建快照，幂等校验涵盖模式，节点能力不足时拒绝执行。部署模板可设置全克隆/链接克隆，用户部署固定继承发布版本。旧 API 未传 clone_mode 时保留兼容默认：镜像全克隆、已有文件直接使用。
