# 创建角色与分配权限

1. 管理员进入“用户与权限 → 角色”，创建自定义角色，或从现有角色“复制为新角色”。
2. 填写唯一角色编码（小写字母开头、3–48 位小写字母/数字/下划线）、显示名称、说明和启用状态。编码创建后不可修改。
3. 选择授权节点上的本人资源，或指定节点上的本人资源。节点范围同时受用户范围与节点授权约束，不会授予他人资源访问权。
4. 按模块勾选权限，可搜索、整组选择。操作自动带入依赖的查看权限；取消依赖权限会取消相关操作。前后端使用同一依赖契约，直接 API 提交仍强制校验。
5. 保存后在“用户”页创建/编辑用户，通过角色复选框分配角色。多个角色权限合并，各操作遵守赋予该操作的角色节点范围，配额不叠加。
6. 自定义角色可修改、禁用或删除；已关联用户的角色必须先迁移用户才能删除。更新采用版本校验，发生冲突需刷新；变更使关联用户旧登录与控制台续期失效。
7. 内置角色不能编辑/删除；复制只复制可独立分配的业务权限，不复制管理员身份或全局访问范围。账号管理、宿主机配置等管理员专属能力不能通过自定义角色提权。
8. 创建、修改、删除记录审计；内置权限同步不会覆盖自定义角色配置。
