# 部署模板库

模板库只列出已发布且未移除的部署版本，不再展示单独的 CPU/内存/磁盘规格记录。创建虚拟机的基本信息页删除规格预设；选择部署模板后仍只需填写虚拟机名称并选择各网卡网络，完整配置由服务端继承并校验。无模板时保留手动创建向导。

管理员直接填写名称、说明、公开范围/指定用户、镜像、节点、计算资源、完整硬件、系统盘与数据盘、网卡、初始化和启动策略，校验通过后原子发布；失败不会残留规格记录或半成品版本。普通用户仅可使用授权范围内的已发布模板，无创建、编辑、删除权限。

- `POST /api/v1/templates/deployments`：元数据与 configuration、constraints 一次提交并发布。
- `GET /api/v1/templates/deployments`：仅返回可见、已发布、未移除版本；授权用户 ID 仅管理员可读。
- `PATCH /api/v1/template-versions/{id}`：重新验证全部配置并发布新版本，替代被编辑版本；原版本配置不变，保留追溯。模板名称、说明与授权范围属于模板系列，同系列版本共享。
- `DELETE /api/v1/template-versions/{id}`：移除指定版本、禁止新部署，不删除已有虚拟机、磁盘、镜像或历史配置；不可再次通过旧发布接口恢复。

编辑与删除以父模板行锁串行化；同版本重复编辑返回 404，避免覆盖其他管理员已提交的替代版本。新版本号递增并保留历史编号。已有实例与已提交任务使用创建时的配置快照，不会随模板替换改变硬件。旧规格 API 保留兼容性，但 UI 不再暴露独立规格流程；旧数据不自动清除。
